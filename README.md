# 🍗 Brakebush Chicken Tycoon

An idle clicker game set in a chicken factory. Tap to bread chicken, buy equipment, unlock new recipes, and open new plants for permanent ⭐ bonuses.

Play it in any browser (phone or desktop) via GitHub Pages. Progress saves in your browser.

_An unofficial, just-for-fun fan game. Not affiliated with or endorsed by any company._
